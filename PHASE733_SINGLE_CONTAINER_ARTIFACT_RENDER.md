
# Phase 733 Single-Container Artifact Render

## Change

Artifact Preview now prioritizes the actual visual artifact block as a single rendered container.

## Product Requirement

The preview should show what the artifact looks like.

It should not turn the artifact into report sections like Summary, Deliverable, Details, Recommendations, or Outcome when a visual artifact block exists.

## Scope

Frontend preview renderer only.

## Safety Boundary

No execution bridge activation.

No orchestration mutation.

No database mutation.

No persistence mutation.

No lifecycle authority mutation.

No Matilda execution authority.

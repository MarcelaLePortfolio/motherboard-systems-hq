# Frontend Reference

This directory contains reusable frontend modules and implementation references.

These files are provided to identify reusable logic and components.

They are not intended to define the application's overall architecture.

## Guidance

Evaluate existing modules before recommending new implementations.

You may:

- reuse existing components
- adapt existing components
- extract reusable logic
- recommend replacement when justified

Do not assume the included modules determine:

- application structure
- routing
- navigation
- workspace organization
- state architecture

The UI shell should emerge from backend contracts, architectural principles, and operator workflows rather than from existing implementation fragments.

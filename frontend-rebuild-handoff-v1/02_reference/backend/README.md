# Backend Reference

This directory contains backend reference artifacts included to help explain the frontend's operating environment.

These artifacts are not intended to represent the complete backend.

## Guidance

Treat backend contracts as authoritative where provided.

Do not infer missing contracts from their absence.

If additional backend information appears necessary, explicitly identify:

- what information is needed
- why it is needed
- what uncertainty it resolves

Do not invent backend behavior to compensate for missing evidence.

The frontend should render backend truth rather than create it.

- No active runtime caller exists for invokeEllisFromEnvelope(...).

- Package does not own assignment.

- Governance Validation derives requirements but does not assign actors.

Conclusion:

The first legitimate caller for Ellis is not yet implemented.

Therefore, no runtime integration should be added yet.

- tasks.claimed_by

- task_events.actor

Canonical assignment concepts searched:

Result:

Canonical assignment fields appear in governance documentation, especially the Envelope specification, but were not found as active persisted runtime fields in server/src/routes/drizzle/sql/docs search scope.

Boundary conclusion:

Worker claim persistence supports execution/worker coordination.

It does not satisfy Ellis-owned assignment authority as specified by governance docs.

Current classification:

- Routing primitive: implemented.

- Scheduling eligibility primitive: implemented.

- Worker claim/actor persistence: implemented.

- Canonical Ellis assignment mutation/persistence: not found.

- Lifecycle Authority: remains closed.

- Assignment Authority: future corridor supported by repository evidence.

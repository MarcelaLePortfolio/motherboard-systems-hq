Intent → Artifact Snapshot → Preview/Diff → Matilda Interpretation → Execution → Reconciliation

- deterministic comparison assertions

- explicit evidence chains

- read-only overlays

- rollback-safe planning

Semantic inspection remains adjacent-to-runtime.

Semantic inspection does not become runtime authority.

- Matilda approval

- structured diff

- rollback proof

- reconciliation

- execution audit

- governed execution lifecycle

# Executive Inbox Presentation Refactor

Status: Approved implementation direction

## Goal

Transform the Executive Inbox into the successor of the Packages workspace.

The Packages workspace is not being replaced functionally.

Its presentation model is being absorbed into Executive Inbox.

## Preserve From Packages

Presentation only.

- two-column master/detail layout
- compact review cards
- clear selection state
- readable typography
- restrained spacing
- concise summaries
- badge treatment
- close-detail behavior
- efficient scrolling
- overall visual density

## Preserve From Executive Inbox

Meaning only.

Every inbox item represents an executive decision.

The detail pane answers:

- What decision is being requested?
- Why is this decision required?
- What changes if approved?
- What evidence supports it?
- What remains uncertain?
- What happens next?

## Result

The Executive Inbox becomes the single executive review surface.

Packages become an implementation artifact rather than an executive destination.

Eventually:

Dashboard
↓

Executive Inbox
↓

Departments

No separate Packages workspace.

## Authorized Scope

Presentation refactor only.

No runtime changes.

No Approval execution.

No Canonical Package mutation.

No Request Changes.

No Execution Authorization.

No notification routing.

No backend modifications.

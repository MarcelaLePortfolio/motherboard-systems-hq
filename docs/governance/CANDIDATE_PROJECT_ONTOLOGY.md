
# Candidate Project Ontology

Status: CANDIDATE

## Purpose

Investigate what constitutes a Project within Motherboard.

This corridor exists because Repository Registry work revealed that Project Root and Git Repository may be necessary infrastructure without being sufficient to establish a Project.

---

## Motivation

During Repository Registry and Active Context reconciliation, a distinction emerged between:

- Project Root

- Git Repository

- Repository Registry Entry

- Project

A Project Root may exist while empty.

A Git Repository may exist while empty.

This raised the question:

Does a Project exist merely because its infrastructure exists, or does it come into existence through an organizational event?

---

## Candidate Investigation Questions

- What is the first event that brings a Project into existence?

- Is user intent sufficient to create a Project?

- Is registration sufficient to create a Project?

- Is the first Package required?

- Can Project infrastructure exist before a Project exists?

- Can a Project exist without a Package?

- Can a Project exist before organizational governance admits it?

---

## Candidate Principle

Project Root and Git Repository may be foundational resources for a Project without being identical to the Project itself.

Infrastructure may precede organizational existence.


# Candidate Session Completion Strategy

Status: CANDIDATE

Purpose:

Investigate whether Matilda should adapt collaboration strategy based upon available session time while preserving architectural quality, continuity, and user satisfaction.

---

## Motivation

Users frequently work within bounded time windows.

Available session time may influence how collaboration should be optimized without changing reasoning quality.

---

## Candidate Investigation Questions

- Should available time become an explicit collaboration input?

- How should Matilda estimate whether a coherent unit of work can be completed before a session ends?

- When should Matilda recommend beginning a new corridor?

- When should Matilda recommend wrapping up instead?

- How should continuity be preserved when time is limited?

- How can partially completed work be minimized without discouraging productive exploration?

---

## Candidate Principle

Optimize for coherent completion rather than maximum throughput.

A completed unit of work often provides greater continuity value than several partially explored directions.

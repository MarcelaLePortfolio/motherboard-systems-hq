## Interpretation

Active values describe:

- current classifier emission behavior

- currently observed runtime metadata vocabulary

Reserve values describe:

- schema-authorized future vocabulary

- currently unused semantic contract space

Reserve values do not imply:

- renderer authority

- orchestration authority

- execution branching

- retry influence

- persistence expansion

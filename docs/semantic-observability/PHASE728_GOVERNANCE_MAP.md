# Core Architectural Doctrine

The semantic substrate was intentionally stabilized as:

- additive

- observational

- artifact-scoped

- runtime-attached

- renderer-independent

- non-authoritative

This doctrine remains authoritative unless explicitly superseded by a future approved corridor.

---

# Important Conceptual Distinctions

## Runtime-Attached ≠ Runtime-Authoritative

Semantic metadata may exist inside runtime artifacts without governing execution behavior.

---

## Schema Vocabulary ≠ Runtime Behavior

Schema-authorized values do not imply active runtime usage.

---

## Observability ≠ Orchestration

Semantic inspection visibility does not imply execution control authority.

---

## Metadata ≠ Policy

Semantic metadata may describe the system without governing the system.

---

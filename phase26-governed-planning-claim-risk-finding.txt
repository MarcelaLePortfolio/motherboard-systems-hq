Governed planning task records can currently match the Phase 26 no-lease claim scope if the worker is run with phase32_claim_one.sql.

- status: queued

- action_tier: A

- mode: planning_only

- status IN ('queued','delegated')

- source = governed_planning

- payload/meta governed_planning = true

Conclusion:

Until a governed execution bridge exists, governed_planning task records should be excluded from worker claim scope.

Governed planning task records are visibility/planning artifacts, not executable work units.


# Renderer Consultation Boundary Map

STATUS: STRICTLY NON-AUTHORITATIVE

PURPOSE:

Define the maximum allowable interaction boundary between semantic observability systems and Preview rendering systems during Phase 731.

AUTHORITATIVE SYSTEMS:

- renderer composition layer

- artifact persistence layer

- execution pipeline

- retry architecture

- orchestration routing

- SSE event infrastructure

NON-AUTHORITATIVE SYSTEMS:

- semantic observability

- section extraction

- composition hint inspection

- preview diagnostics

- classification refinement

ALLOWED CONSULTATION PATTERN:

Renderer MAY:

- inspect semantic metadata

- inspect section observability hints

- inspect additive classification signals

Renderer MUST NOT:

- delegate rendering authority to semantics

- mutate layout through semantic instruction

- alter persistence contracts

- alter execution flow

- alter retry behavior

- alter orchestration logic

SEMANTIC SUBSTRATE LIMITATIONS:

Semantic systems remain:

- observational

- additive

- rollback-safe

- renderer-independent

- artifact-scoped

PHASE 731 SAFETY PRINCIPLE:

Semantic infrastructure may inform inspection and diagnostics only. Renderer authority remains fully deterministic and renderer-owned.

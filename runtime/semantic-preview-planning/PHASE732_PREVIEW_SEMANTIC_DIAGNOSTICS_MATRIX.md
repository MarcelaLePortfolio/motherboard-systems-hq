
# Phase 732 Preview Semantic Diagnostics Matrix

## Status

Phase 732 Preview semantic diagnostics matrix established.

This document defines the allowed diagnostic classes that may become observable around Preview inspection surfaces while preserving strict observability-only containment.

## Objective

Expand Preview-adjacent semantic inspection capability without granting semantic authority over:

- renderer behavior

- layout composition

- execution systems

- orchestration

- task routing

- persistence contracts

- markdown rendering

- Preview authority
